# Politica de confiabilidade

- `raw_source_reference`: referencia direta a uma fonte do corpus.
- `source_grounded_synthesis`: interpretacao estruturada sustentada pelo corpus.
- `temporal_sensitivity: alta`: pode mudar com regra, produto, banco, convenio ou periodo.
- `validation_status: validar_condicao_atual_quando_aplicavel`: o contexto pode ser usado para raciocinar, mas nao para afirmar condicao vigente sem verificacao.

Nunca converter numero historico, opiniao de entrevistado, propaganda, fluxo de uma empresa ou demonstracao de um sistema em regra universal do mercado.
