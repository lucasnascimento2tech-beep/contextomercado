# Como ler o cerebro

1. Use `00_MODELO_MENTAL` para entender o todo.
2. Use dominios para aprofundar entidades, produtos, comercial, operacional, financeiro, gestao, tecnologia e riscos.
3. Use `10_SITUACOES_REAIS` quando a pergunta vier como problema concreto.
4. Use `11_PRINCIPIOS_DO_MERCADO` para recuperar regras de raciocinio reutilizaveis.
5. Use `12_LINGUAGEM_DO_MERCADO` para interpretar termos e jargoes.
6. Use `14_DIVERGENCIAS_E_VALIDACAO` antes de transformar uma pratica observada em verdade universal.
7. Sempre preserve a diferenca entre fonte, sintese e regra vigente.
